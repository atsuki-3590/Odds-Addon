# オッズ歪みチェッカー（自分用プロトタイプ）

開いているオッズページ（2連単・2連複）の表示内容を読み取り、
**2連単の裏表2点を合わせた合成オッズ** と **2連複オッズ** を比べて、どちらが得かをサイドパネルに表示する Chrome 拡張（Manifest V3）です。

対象ページ：`https://www.boatrace.jp/owpc/pc/race/odds2tf?rno=<R>&jcd=<場>&hd=<日付>`（「オッズ」→「2連単・2連複」タブ）。
24場・全レース共通で動きます（場ごとの分岐はありません）。

## 計算

艇 i, j の組について

| 記号 | 意味 |
|---|---|
| a | 2連単 i→j のオッズ |
| b | 2連単 j→i のオッズ |
| S | 合成オッズ = 1 / (1/a + 1/b) |
| C | 2連複 i=j のオッズ |
| R | C / S |

- R > 1 → 2連複のほうが得、R < 1 → 2連単2点買いのほうが得
- 全賭式の払戻率が同じ（75%）なので控除率の補正はしない
- オッズは 0.1 刻みで丸められているため、R が 0.95〜1.05 程度はノイズ扱い。
  強調表示のしきい値（初期値 R ≥ 1.10 / R ≤ 0.90）はサイドパネルで変更できます（`chrome.storage.local` に保存）
- 欠場・発売なし・「-」など数値でない値は計算対象から外します（その組は「—」表示で末尾へ）

## 導入手順（PC の Chrome：拡張機能）

1. GitHub のリポジトリページで、ブランチを `claude/boatrace-odds-comparison-extension-wefz51` に切り替え（main に取り込んだ後は main のままで OK）、
   **Code → Download ZIP** でダウンロードして、わかりやすい場所（例: `ドキュメント\odds-addon`）に展開する
   （git が使えるなら `git clone` でも可。更新は `git pull` で取り込めます）
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** をオン
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、`manifest.json` があるフォルダを選ぶ
5. ツールバーの拡張機能アイコン（パズルのピース）から「オッズ歪みチェッカー」をピン留めしておくと便利
6. 2連単・2連複のオッズページを開き、拡張機能のアイコンをクリックするとサイドパネルが開きます

※ 展開したフォルダを消したり移動したりすると拡張が読み込めなくなります。
コードを更新したら `chrome://extensions` で拡張機能の ⟳（再読み込み）を押し、オッズページもリロードしてください。

## スマホ（Android の Chrome）で使う：ブックマークレット

Android の Chrome は拡張機能に対応していないため、同じ計算をする**ブックマークレット**を用意しています。
PC の Chrome で登録して、ブックマーク同期でスマホに送るのが一番簡単です。

1. ダウンロードしたフォルダの `dist/install.html` を PC の Chrome で開き、「オッズ比較」ボタンをブックマークバーへドラッグ
2. PC とスマホの Chrome で同じ Google アカウントにログインし、同期の「ブックマーク」をオン
3. スマホでオッズページを開き、**アドレスバーに「オッズ比較」と入力 → 候補の★ブックマークをタップ**
   （ブックマーク一覧からタップしても動きません。Android の Chrome の仕様です）
4. 結果ページが開きます。「← オッズページに戻る」かブラウザの戻るで元のページへ。
   最新のオッズで計算し直すときは、オッズページの「更新」を押してからもう一度実行

- 対象は PC 版のオッズページ（`/owpc/pc/race/odds2tf`）です。スマホから開いても PC 版がそのまま表示されます。
  スマホ版（`/owsp/sp/`）や 3連単などのページで実行すると、同じレースの PC 版 2連単・2連複ページへ移動するか確認します
- 公式ページの DOM は書き換えず、結果は別ページ（Blob）に表示します。通信・外部送信はしません
- しきい値はその端末のブラウザに保存されます
- 中身は拡張機能と同じ `src/parser.js` / `src/calc.js` / `src/view.js` です。ソースを変更したら
  `npm run build` で `dist/` を作り直してください（`npm test` が古い `dist/` を検出します）

## 使い方

- サイドパネル上部：レース場名・レース番号・レース名、日付・締切予定時刻・ページに表示されている「オッズ更新時間」（締切後のページなら「締切時オッズ」）
- 表：15組を R の降順で表示（組 / a / b / 合成S / 2連複C / R / 得な買い方）
  - 青系：2連複が得（R ≥ 上側しきい値）
  - 橙系：2連単2点が得（R ≤ 下側しきい値）
  - 灰色：しきい値内（ノイズの範囲）または計算不可
- ページの「更新」ボタンは現状ページ全体の再読み込みなので、読み込み直後に自動で再計算されます。
  ページ内で表だけが書き換わった場合も MutationObserver で検知して再計算します
- 欠場艇を含む組、発売票数0（「0.0」表示）の組は計算対象外として末尾に「—」で表示します

## 守っていること

- 読むのは **ユーザーが開いているページの DOM だけ**。バックグラウンドでの定期取得や別ページへの fetch はしない
- 公式ページの DOM は書き換えない（表示はサイドパネルのみ）
- 外部へのデータ送信なし、外部ライブラリなし（素の JavaScript）
- コンテンツスクリプトはオッズページの URL パターンにだけ注入

## 構成

```
manifest.json
src/
  parser.js      Document → { a: {"1-2": 5.3, ...}, c: {"1=2": 3.1, ...} }（純粋関数）
  calc.js        合成オッズ・比率・判定（純粋関数）
  content.js     ページを解析して結果を送る／MutationObserver で再解析
  view.js        結果の表としきい値フォームの描画（サイドパネルとブックマークレットで共通）
  background.js  結果を chrome.storage.session にタブ単位で保存、サイドパネルの開閉設定
sidepanel.html / sidepanel.css / sidepanel.js   表示としきい値設定
bookmarklet/     スマホ用ブックマークレットの本体（main.js）と結果ページ用スクリプト（result.js）
scripts/build-bookmarklet.js   dist/bookmarklet.txt と dist/install.html を生成
dist/            生成済みのブックマークレットと登録用ページ
fixtures/        オッズページの HTML（テスト用）
test/            node:test のユニットテスト（test/helpers/mini-dom.js はテスト専用の簡易 HTML パーサー）
```

### ページ構造のメモ（パーサーが頼りにしているもの）

- 見出し `.title7_mainLabel` が「2連単オッズ」「2連複オッズ」の表を、直後の `.table1 table` から読む
- 列と1着艇の対応は `thead` の艇番 `th`（1〜6）から、2着艇は各行の艇番 `td` から読む。オッズは `td.oddsPoint`
- 欠場は `td.oddsPoint.is-miss`（「欠場」）、1000倍以上は「1244」のように小数点なし
- 場名は `.heading2_area img[alt]`（取れなければ jcd→場名の対応表）、レース番号などはオッズ種別タブのリンク
- 締切予定時刻は表示中レースの列から読む（`is-activeColor1` は「発売中のレース」の印なので使わない）

## fixtures

`odds2tf_<日付>_<jcd>_<R>_<状態>.html`（状態: `live` 発売中 / `closed` 締切後 / `kekkajo` 欠場あり / `nodata` データなし）。
2026-11-14 開催の14場分を含みます。全 fixture に共通の性質（キー形式・メタ情報とファイル名の一致など）をテストしているので、
新しい場・状態のページを追加するとそのまま回帰テストになります。Chrome で保存する場合は「ウェブページ、完全」で保存し、
HTML ファイルだけを上の名前で置いてください（`*_files/` は `.gitignore` 済み）。

データの流れ：`content.js` →（`runtime.sendMessage`）→ `background.js` →（`storage.session` の `tab:<id>`）→ `sidepanel.js`
