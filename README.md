# オッズ歪みチェッカー（自分用プロトタイプ）

開いているオッズページ（2連単・2連複）の表示内容を読み取り、
**2連単の裏表2点を合わせた合成オッズ** と **2連複オッズ** を比べて、どちらが得かをサイドパネルに表示する Chrome 拡張（Manifest V3）です。

> ⚠ 開発中：DOM パーサー（`src/parser.js` の `parseOdds` / `parseRaceMeta`）は、`fixtures/` に保存した実ページの HTML を見てから実装します。

## 計算

艇 i, j の組について

| 記号 | 意味 |
|---|---|
| a | 2連単 i→j のオッズ |
| b | 2連単 j→i のオッズ |
| S | 合成オッズ = 1 / (1/a + 1/b) |
| C | 2連複 i=j のオッズ |
| R | C / S |

- R > 1 → 2連複のほうが得、R < 1 → 2連単2点買いのほうが得
- 全賭式の払戻率が同じ（75%）なので控除率の補正はしない
- オッズは 0.1 刻みで丸められているため、R が 0.95〜1.05 程度はノイズ扱い。
  強調表示のしきい値（初期値 R ≥ 1.10 / R ≤ 0.90）はサイドパネルで変更できます（`chrome.storage.local` に保存）
- 欠場・発売なし・「-」など数値でない値は計算対象から外します（その組は「—」表示で末尾へ）

## 導入手順

1. このリポジトリをローカルに clone（または ZIP でダウンロードして展開）
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** をオン
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、`manifest.json` があるフォルダを選ぶ
5. ツールバーの拡張機能アイコン（パズルのピース）から「オッズ歪みチェッカー」をピン留めしておくと便利
6. 2連単・2連複のオッズページを開き、拡張機能のアイコンをクリックするとサイドパネルが開きます

コードを変更したら `chrome://extensions` で拡張機能の ⟳（再読み込み）を押し、オッズページもリロードしてください。

## 使い方

- サイドパネル上部：レース場名・レース番号・ページに表示されているオッズ取得時刻
- 表：15組を R の降順で表示（組 / a / b / 合成S / 2連複C / R / 得な買い方）
  - 青系：2連複が得（R ≥ 上側しきい値）
  - 橙系：2連単2点が得（R ≤ 下側しきい値）
  - 灰色：しきい値内（ノイズの範囲）または計算不可
- ページの「オッズ更新」で表が変わると自動で再計算します（MutationObserver）

## 守っていること

- 読むのは **ユーザーが開いているページの DOM だけ**。バックグラウンドでの定期取得や別ページへの fetch はしない
- 公式ページの DOM は書き換えない（表示はサイドパネルのみ）
- 外部へのデータ送信なし、外部ライブラリなし（素の JavaScript）
- コンテンツスクリプトはオッズページの URL パターンにだけ注入

## 構成

```
manifest.json
src/
  parser.js      Document → { a: {"1-2": 5.3, ...}, c: {"1=2": 3.1, ...} }（純粋関数）
  calc.js        合成オッズ・比率・判定（純粋関数）
  content.js     ページを解析して結果を送る／MutationObserver で再解析
  background.js  結果を chrome.storage.session にタブ単位で保存、サイドパネルの開閉設定
sidepanel.html / sidepanel.css / sidepanel.js   表示としきい値設定
fixtures/        保存したオッズページの HTML（テスト用）
test/            node:test のユニットテスト
```

データの流れ：`content.js` →（`runtime.sendMessage`）→ `background.js` →（`storage.session` の `tab:<id>`）→ `sidepanel.js`
